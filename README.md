# CoreBridge Cross-Training Arena

Interactive training games for Support staff cross-skilling between **Classic (V2)** and **V3** (**Legacy** + **Evo** UIs).

## Product naming

| Name | Meaning |
|------|---------|
| **Classic** | V2 |
| **Legacy** | Older UI of V3 |
| **Evo** | Newer UI of V3 |

## Games

| Game | Audience | Focus |
|------|----------|--------|
| **Classic Circuit** | V3 Support | Classic (V2) identification, routing, KB hygiene |
| **V3 Gauntlet** | V2 Support | Legacy UI + Evo UI ticket scenarios (labeled per question) |

Each run is **10 scenario questions** with coaching tips, streak bonuses, and a **local leaderboard**.

## Visual system

Matched to [corebridge.net](https://www.corebridge.net/):

- Display: **Radio Canada Big**
- Body: **IBM Plex Sans**
- Labels/CTAs: **IBM Plex Mono**
- Dark UI, lime brand accent (`#99ca3d` / `#a8d65c`)
